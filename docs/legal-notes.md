# 푸터·법적 문서·사업자 정보 참고 자료

## 사업자 정보 확인

국세청 공식 안내는 홈택스의 사업자상태조회 서비스를 이용하도록 안내합니다.

- 국세청 안내: https://www.nts.go.kr/nts/cm/cntnts/cntntsView.do?mi=11446&cntntsId=8815
- 홈택스: https://www.hometax.go.kr/
- 국세청 사업자등록정보 진위확인·상태조회 Open API 안내: https://www.data.go.kr/data/15081808/openapi.do

현재 사이트의 **사업자정보 보기** 버튼은 홈택스 공식 홈페이지로 연결하고, 사업자등록번호 `522-28-01731`을 푸터에 표시합니다. 국세청 Open API는 사업자번호만으로 완성되는 공개 연동이 아니며, API 인증키와 사업자번호·개업일자·대표자명 등 추가 값이 필요하므로 임의로 조회 결과를 표시하지 않았습니다. 실제 사업자명·대표자·주소·통신판매업 신고번호는 관리자에서 확인 후 입력해야 합니다. 관리자에서 홈택스 또는 별도 공식 조회 링크를 바꿔 저장할 수 있습니다.

## 문서 작성 참고

개인정보처리방침 기본 문안은 개인정보보호위원회의 개인정보 처리방침 안내를 참고해 수집 항목, 이용 목적, 보유 기간, 제3자 제공·처리위탁, 이용자 권리, 보호책임자 항목을 포함했습니다.

- 개인정보보호위원회: https://pipc.go.kr/np/default/page.do?mCode=H010000000
- 개인정보 포털: https://www.privacy.go.kr/front/contents/cntntsView.do?contsNo=283

기본 문안은 템플릿이며 법률 자문이나 최종 확정본이 아닙니다. 실제 사업자 정보, 결제·이메일 위탁업체, 보유 기간, 환불 정책 및 개인정보 보호책임자 정보를 관리자에서 확정한 뒤 공개해야 합니다.
